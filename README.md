# AntCade
A Game done in Godot for the Jame Gam, event run by Hack Club!

<img width="320" height="180" alt="image" src="https://github.com/user-attachments/assets/ec0a82a6-d79c-43c1-986e-30da2835da2f" />

### Lore
Your dream is to become the greatest gamer in the world, but your friends and family keep telling you that you can't do it because you're JUST A LITTLE GUY. ***PROVE THEY ARE WRONG***

### Built With
- Engine: Godot
- Language: GDScript
- Platform: Web (HTML5)
